SinterDB 0.0.3 introduces the first functional database server lifecycle.

## Highlights

- TCP server with multiple client connections
- Protocol handshake and capability advertisement
- Ping request handling
- In-memory database and collection catalog
- serverInfo, listDatabases, createCollection, and listCollections commands
- Structured JSON lifecycle logging
- Graceful SIGINT and SIGTERM shutdown
- Bundled sinterd executable
- Temporary-port test-server utilities

## Current limitations

Document storage, CRUD operations, persistence, indexes, and the public driver connection API are planned for later milestones.
