# SinterDB 0.0.5 — Insert and Point Read

SinterDB `0.0.5` introduces the first document insertion and point-read operations across the server, storage engine, and official Node.js driver.

**Full Changelog**: https://github.com/Killer88967/sinterdb/compare/v0.0.4...v0.0.5

## Highlights

- Added `CustomId` generation, comparison, and binary protocol serialization
- Added in-memory document storage
- Added document-size and nesting-depth validation
- Added `insertOne`
- Added ordered `insertMany`
- Added `findOne`
- Added typed equality filters
- Added duplicate identifier detection
- Added structured partial-failure information for ordered bulk inserts
- Added typed driver results for inserted and retrieved documents
- Added end-to-end driver, server, protocol, and storage integration coverage

## Driver example

```ts
import { SinterClient } from "sinterdb";

interface User {
  name: string;
  age: number;
}

const client = new SinterClient("sinterdb://127.0.0.1:4721/application");

await client.connect();

const users = client.db().collection<User>("users");

const insertion = await users.insertOne({
  name: "Ada",
  age: 36,
});

const user = await users.findOne({
  age: 36,
});

console.log(insertion.insertedId);
console.log(user);

await client.close();
```

> [!WARNING]
> SinterDB remains experimental. Documents are currently stored in memory and are lost when the server stops. APIs and protocol details may change before `1.0.0`.

See the included package changelogs and the project roadmap for additional details.
