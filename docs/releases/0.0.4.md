SinterDB 0.0.4 introduces the first functional Node.js driver connection API.

## Highlights

- `SinterClient` with connection and shutdown lifecycle management
- Connection-string parsing for `sinterdb://host:port/database`
- Protocol handshake and capability negotiation
- Ping requests with round-trip timing
- Connection, request, and idle socket timeouts
- Typed connecting, connected, closed, and error events
- Public driver error hierarchy with stable error codes
- Typed `SinterDatabase` and `SinterCollection<TDocument>` handles
- Real server integration tests
- Repeated connection-cycle testing without leaked connections

## Current limitations

Document insertion, point reads, filters, cursors, persistence, and indexes are planned for later milestones.

The packages are currently distributed as GitHub Release artifacts and have not been published to npm.
