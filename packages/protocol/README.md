# SinterDB Protocol

Internal wire-protocol primitives shared by the SinterDB server and official Node.js driver.

> [!WARNING]
> This is a low-level implementation package. Its API is unstable before
> SinterDB 1.0 and should normally be consumed through the official driver.

## Specifications

See the [SinterDB Wire Protocol Version 1](../../docs/protocol/wire-protocol-v1.md)
specifications.
